# 商談解析システム（Google Apps Script 版）

Fly.io / Docker / Next.js を使わず、**Google スプレッドシート + Apps Script** だけで完結する構成です。ホスティング費用ゼロ、CORSなし、外部AI APIキーの取得・課金も一切不要（キーワード・ルールベースで解析するため）。社内の誰でも同じURLからアクセスできます。

## できること

- 文字起こし済みの商談テキストを貼り付けて解析（キーワードベースでディスカッション項目を抽出）
- 法人（corporate）→ 店舗（company）の階層で自動整理
- 一覧・キーワード検索・法人カルテ（店舗ごとの課題有無を一覧化）

## 解析エンジンについて（重要）

外部のAI API（Gemini/Claude等）は一切使用しません。`Code.gs` 内のキーワード辞書とルールで、文字起こしテキストから「①採用・人手」「②集客・売上」「③予約・業務効率」「④インバウンド集客」に関する課題を検出します。

- 「人手が足りなくて困っている」のように、キーワード（不足・困っ・悪い・課題 等）を含む明示的な言い回しは拾えます
- 遠回しな表現や、キーワードを含まない文脈依存の課題までは拾えません
- DXソリューション提案は、検出したカテゴリに応じた定型文から選ばれます（AIによる商談内容に即したオーダーメイドの提案ではありません）

APIキーの取得・課金・利用制限・CORSといった、これまで発生していたトラブルの原因が構造的になくなっています。キーワード辞書は `Code.gs` の `CATEGORY_KEYWORDS_` / `ISSUE_KEYWORDS_` / `DX_SOLUTIONS_BY_CATEGORY_` で調整できます。実際の商談で使われる言い回しに合わせてキーワードを追加していくことで、検出精度を上げられます。

## セットアップ手順（初回のみ）

### 1. スプレッドシートを新規作成

Google スプレッドシートを新規作成します（名前は自由、例:「商談解析システム」）。このスプレッドシートがデータベースになります。

### 2. Apps Script エディタを開く

スプレッドシートのメニューから **拡張機能 → Apps Script** を開きます。

### 3. このフォルダのコードを貼り付け

デフォルトで `Code.gs`（中身は空の `myFunction`）が1つあるはずです。以下のように置き換えます：

1. `Code.gs` の中身を全て削除し、このリポジトリの [`gas/Code.gs`](./Code.gs) の内容を貼り付ける
2. 左側の「+」→「HTML」で `Index` という名前のファイルを新規作成し、[`gas/Index.html`](./Index.html) の内容を貼り付ける
3. 左側の歯車アイコン（プロジェクトの設定）→「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れると `appsscript.json` が編集できるようになるので、[`gas/appsscript.json`](./appsscript.json) の内容に置き換える

### 4. Web アプリとしてデプロイ

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択で「ウェブアプリ」を選ぶ
3. 「次のユーザーとして実行」: **自分**
4. 「アクセスできるユーザー」: 組織内の全員に使わせたい場合は「〇〇（組織名）内の全員」。社外を含め誰でも使えるリンクにしたい場合は「全員」
5. 「デプロイ」をクリックし、発行された **ウェブアプリのURL** を控える

このURLをブックマークすれば、以後は毎回このURLを開くだけで使えます。APIキーの設定は不要です。

### 5. 動作確認

発行されたURLを開き、テキスト解析タブに適当な文字起こしテキストと店舗名を入力して「解析を開始」。エラーが出る場合は Apps Script エディタの「実行数」ログでエラー内容を確認してください。

## コードを更新したとき

Apps Script エディタで直接編集するか、`clasp`（Google公式CLI）を使ってこのリポジトリから直接 push することもできます:

```bash
npm install -g @google/clasp
clasp login
cd gas
clasp create --type webapp --title "商談解析システム" --rootDir .
# または既存プロジェクトに紐づける場合は .clasp.json に scriptId を設定
clasp push
clasp deploy
```

コードを変更したら「デプロイ」→「デプロイを管理」→ 既存のデプロイの鉛筆アイコン →「バージョン: 新バージョン」→「デプロイ」で更新します（URLは変わりません）。

## データ構造

スプレッドシートに自動で以下のシートが作成されます:

- **Meetings** — 商談1件＝1行。店舗名・法人名・要約・信頼度（検出網羅率）・各種JSON（discussions/priority_issues/dx_solutions）
- **PriorityIssues** — 優先課題1件＝1行（検索・法人カルテの集計用に正規化したもの）

スプレッドシート自体をチームで共有すれば、Apps Script を経由せず直接 Sheets の集計機能（ピボットテーブル、QUERY関数など）で分析することもできます。

## セキュリティ

- 外部AI APIを呼び出さないため、商談内容が社外のサービスに送信されることがありません（すべてGoogleアカウント内で完結）
- Web アプリのアクセス範囲（デプロイ時の「アクセスできるユーザー」設定）で利用者を制限できます
- スプレッドシート自体の共有権限は、通常の Google スプレッドシートと同様に管理できます
